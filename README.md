# Ryanair Flight Operations Analytics

An end-to-end data analytics project examining 740,787 recorded flights from July 2025 to July 2026 using Python, Pandas, MySQL, and Power BI.

## Project Overview

This project explores recorded flight activity, airport and route patterns, and aircraft model distributions through data cleaning, SQL analysis, and interactive Power BI dashboards.

## Tools and Technologies

- Python (Pandas, NumPy)
- MySQL
- Power BI
- Power Query
- DAX

## Dashboard Pages

1. Flight Operations Overview
2. Airport & Route Analysis
3. Fleet Analysis

## Data Source

EUROCONTROL OPDI flight records.

**Note:** The dataset contains incomplete airport information and varying monthly coverage. Results describe available records rather than Ryanair's complete flight operations.
